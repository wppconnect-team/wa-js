    call.audio_frame

    "call.audio_frame": {
        format: "float32" | "int16-base64";
        id?: string;
        sampleRate: number;
        samples: string | Float32Array<ArrayBufferLike>;
        source: "remote" | "local";
        timestamp: number;
    }

    Triggered for each audio frame of the active call, after WPP.call.enableAudioCapture(). Frames are 16 kHz mono, 60 ms long (960 samples).

    Type Declaration

    • format: "float32" | "int16-base64"
    • Optionalid?: string

      The active call id, when there is one

    • sampleRate: number
    • samples: string | Float32Array<ArrayBufferLike>

      Float32Array for float32, base64 of little-endian Int16 PCM for int16-base64

    • source: "remote" | "local"

      remote: what you hear; local: what you send

    • timestamp: number

      performance.now() when the frame was captured

    Example

    WPP.call.enableAudioCapture({ format: 'int16-base64' });
    WPP.on('call.audio_frame', (frame) => {
      if (frame.source === 'remote') {
        // send frame.samples to a speech-to-text service
      }
    });
